# Sliver Rust 版本汉化方案文档

## 项目概述

本文档描述了 Sliver Rust 重构版本的完整汉化方案，包括多语言支持架构、汉化内容、测试框架和验证结果。

**项目名称**: Sliver Rust 重构版本
**版本**: 0.1.0
**汉化目标**: 全量汉化，中英文可切换，功能1:1复刻

---

## 1. 汉化方案设计

### 1.1 多语言框架选型

**选择库**: `rust-i18n`

**选型理由**:
- 轻量级：不依赖大型国际化框架
- Rust原生：完全兼容 Rust 生态系统
- 易集成：通过宏系统简化使用
- 类型安全：编译时检查翻译键

**替代方案对比**:
- `fluent-rs`: 功能更强大但复杂度较高
- `gettext-rs`: 传统方案但不够现代化
- `i18n-embed`: 编译时嵌入但灵活性较差

### 1.2 架构设计

```
sliver-rust/
├── client/           # 客户端（CLI）
├── server/           # 服务端（守护进程）
├── shared/           # 共享库
├── locales/          # 语言资源文件
│   ├── zh-CN.json  # 中文翻译
│   └── en.json      # 英文翻译
└── tests/            # 自动化测试
```

**语言切换方式**:
1. 命令行参数：`--language=zh-CN` 或 `--language=en`
2. 环境变量：`SLIVER_LANG=zh-CN`
3. 配置文件：在配置文件中设置默认语言

**默认语言**: 中文（zh-CN）
**回退语言**: 英文（en）

## 3. 技术实现细节

### 3.1 多语言加载机制

```rust
// 初始化 i18n
rust_i18n::i18n!("locales", fallback = "en");

// 语言切换
fn set_language(lang: &str) {
    let locale = match lang {
        "zh-CN" => "zh-CN",
        "en" => "en",
        _ => "zh-CN",
    };
    rust_i18n::set_locale(locale);
}

// 文本翻译使用
let text = t!("common.welcome");
let version_text = t!("common.version", version = "0.1.0");
```

### 3.2 非侵入式设计

**核心原则**:
- **只替换文本**：不修改任何核心业务逻辑
- **保持API兼容**：所有函数签名和行为保持一致
- **零性能开销**：语言加载仅发生在启动时
- **类型安全**：编译时检查翻译键是否存在

**实现示例**:
```rust
// 原始代码
fn list_sessions() -> Vec<Session> {
    println!("Listing sessions...");
    sessions.clone()
}

// 汉化后代码
fn list_sessions() -> Vec<Session> {
    println!("{}", t!("session.list_header"));
    println!("{}", t!("session.active_sessions", count = sessions.len()));
    sessions.clone()
}
```

```bash

# Release模式编译
cargo build --release

```

```bash

./run_tests.sh
```

### 9.3 使用应用

```bash
# 启动服务端（中文）
./target/debug/sliver-server start --language=zh-CN

# 启动客户端（中文）
./target/debug/sliver-client --language=zh-CN

# 启动客户端（英文）
./target/debug/sliver-client --language=en

# 查看帮助
```

### 9.4 语言切换

```bash

./target/debug/sliver-client --language=en session list

# 通过环境变量切换
export SLIVER_LANG=zh-CN
./target/debug/sliver-client
```
